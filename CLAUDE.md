## Shared layout: always run the sync script

Header/menu, footer (incl. the originality statement), the A–E tab bar and the previous/next links are generated by:

```powershell
node tools/sync-layout.js
```

It also bumps the CSS/JS cache version (`?v=`), converts non-ASCII characters to HTML entities, and reports broken local links. **Run it after every change**, and edit the menu/footer/originality text only inside `tools/sync-layout.js`, never by hand in the pages.

In page files these elements are placeholders the script fills in:
`<header class="site-header">…</header>`, `<footer class="site-footer">…</footer>`, `<nav class="cp-subnav">…</nav>`, `<nav class="cp-pager">…</nav>`.

To add a page: copy a similar page, add it to `PAGES` (and `SUBPAGES` if it belongs under Curriculum & Pedagogy) in the script, then run it.

## Filling in a "Coming soon" section

Placeholders use `<div class="pending">` (and `.artifact`, `.smart-card` cards with a `.pending-tag`). Replace the placeholder with the real content, then:
- set the hub card on `curriculum-pedagogy.html` from `status soon` / "Coming soon" to `status done` / "Published";
- add any new sources to the APA list on `references.html` (alphabetical; add a `used-in` tag);
- put the PDF in `assets/docs/<category>/` (and the original in `Source Documents/`).

Handout word counts: reflective narratives ~100–150 words (A, B, D, E), ~100–125 words (C); S.M.A.R.T. goals use "In order to… so I… I will… by…", relate to her **first three months of employment**, each with 2 strategies (~100 words each).

**Reflective writing, goals, the land acknowledgement and narratives must be Keerthika's own words**: the site carries her signed originality statement. Format and place her text; don't write it for her.

## Rules that matter

- **No title pages** in uploaded documents (handout). The published pedagogical documentation PDF had page 1 (title page with student numbers) removed with `pdf-lib`; the original stays in `Source Documents/`.
- **No home address or phone number** in the cover letter/resume (handout). Her phone was removed from the whole site; contact is email + LinkedIn.
- **Confidentiality:** children only as Child A, B, …; no student numbers or classmates' surnames.
- **Non-ASCII → entities** (the sync script does this). Check: `LC_ALL=C grep -c '[^ -~	]' *.html assets/css/style.css assets/js/main.js` → all 0.
- **Write "Resume", not "Résumé"** (her preference).
- **Hero photo:** keep badges/decorations off the photo itself (handout: professional photo free of filters and embellishments). Originals live in `Source Documents/4 - Photos/`.
- **Roles she is open to:** Early Childhood Educator, Childcare Assistant, Classroom Assistant, Montessori Support Educator, Academic Tutor, Classroom Teacher/Assistant/Co-Teacher (professor asked to include teaching roles).
- **Commit author** for this repo is set locally: `Keerthika Mohanmoorthy <itskeerthi2000@gmail.com>`.
- The folder path contains an apostrophe (`Keerthika's Portfolio`), which breaks bash quoting/heredocs. Prefer PowerShell or Node scripts.
- Regex edits on HTML: never use lazy `[\s\S]*?</span>\s*</span>`-style patterns; they can swallow half a page. Anchor on unique markers.

## Design system (assets/css/style.css)

- Fonts: **Fraunces** (serif) + **Plus Jakarta Sans**; icons: Font Awesome 6.5.2 (cdnjs).
- Colours: `--teal #1f7a72`, `--sun #e8a33d`, `--rose #d9776a`, `--ink #16243a`, `--paper #fbf8f3`. Philosophy facet colours: child `#7c4dcc`, family `#d6457a`, educator `#2f6fd6`, community `#1f8a5b`, environment `#d68910`, Reggio `#e0623a` (same as her poster).
- Menu collapses to a hamburger at **≤1340px** (the full 6-item menu needs ~1340px).
- Components: `.card`, `.bento`, `.timeline`, `.status-list`/`.pill`, `.steps`, `.cta`, `.band`, `.doc-feature`, `.facet`, `.believe-list`, `.cp-hub`/`.cp-card`, `.cp-subnav`, `.cp-pager`, `.pending`, `.artifact`, `.plan-block`, `.smart-card`, `.apa-list`, `.ref-card`, `.cert-card`, `.laws`, `.originality`.
- Kid touches: `data-emoji="🧸"` on a card adds a corner emoji; `<span class="em">` in `.eyebrow` adds a label emoji.
- `main { overflow-x: clip }` prevents the spinning kaleidoscope from causing sideways scroll on phones.

## Interactions (assets/js/main.js)

| Feature | How to use |
| --- | --- |
| Reveal on scroll | `reveal` / `reveal-scale`; `data-stagger="90"` on a parent |
| Headline word animation | `data-split` on an `h1` |
| Count-up numbers | `<span data-count="15">15</span>` |
| Cursor spotlight | class `spot` |
| Magnetic buttons | class `magnetic` |
| 3D portrait tilt | `data-tilt` wrapper with `.tilt` inside |
| Diploma progress bar | `data-progress-start` / `data-progress-end` |
| Floating emojis in headers | automatic on `.hero` / `.page-hero` |
| Welcome avatar popup (waving) | automatic, once per session |
| Page transitions (teal curtain) | automatic for internal links + back/forward |
| Open at top on reload | `history.scrollRestoration = "manual"` |

All motion is disabled under `prefers-reduced-motion`.
